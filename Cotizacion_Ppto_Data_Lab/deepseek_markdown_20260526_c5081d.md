# PROYECTO DE INVERSIÓN – DATALAB
## Facultad de Ciencias Económicas y Administrativas
### Pontificia Universidad Javeriana Cali

**Espacio disponible:** 7.20 m de largo × 4.30 m de ancho = 30.96 m²  
**Capacidad:** 7 puestos de trabajo (6 estándar + 1 avanzado)  
**Usos principales:** Visualización de datos, inteligencia artificial, docencia, investigación aplicada.

---

## 1. ¿Qué es el Datalab?
Entorno integral que reúne herramientas para extracción, transformación y organización de datos, facilitando modelos analíticos orientados a la toma de decisiones. Promueve el análisis mediante guías docentes, casos prácticos y bases de datos, apoyando investigación y docencia.

## 2. Objetivos del laboratorio
1. Promover el uso de herramientas de analítica y visualización accesibles, eficientes y colaborativas.
2. Servir como punto de apoyo para cursos, proyectos de investigación y actividades formativas que requieran análisis cuantitativo.
3. Desarrollar en los estudiantes la capacidad de transformar datos en conocimiento útil.
4. Facilitar el intercambio de experiencias, proyectos y materiales entre docentes, estudiantes y aliados externos.

## 3. Filosofía técnica aplicada
| Objetivo | Decisión de inversión |
|----------|------------------------|
| Herramientas accesibles, eficientes, colaborativas | Equipos costo-eficientes; plataformas colaborativas (JupyterHub) |
| Apoyo a cursos e investigación | Capacidad para correr modelos en aula |
| Transformar datos en conocimiento útil | Suficiente RAM y GPU para datasets reales |
| Intercambio con aliados externos | Espacio flexible, red segura para invitados |
| Código abierto | Hardware que corre bien Linux + Python/R |

## 4. Distribución del espacio (30.96 m²)
- **6 puestos estándar:** 1.20 m ancho × 0.80 m fondo cada uno
- **1 puesto avanzado:** 1.50 m × 0.90 m
- **Área rack/UPS:** 1.00 × 0.80 m
- **Pantalla colaborativa:** 65" o 75" en pared frontal
- **Pasillos centrales:** mínimo 1.20 m

## 5. Especificaciones de equipos

### 5.1 Puestos estándar (6 unidades)
- CPU: AMD Ryzen 7 8700G o Intel i7-14700
- RAM: 32 GB DDR5
- GPU: NVIDIA RTX 4060 (8 GB VRAM)
- Almacenamiento: 1 TB NVMe SSD
- SO: Ubuntu 24.04 LTS + Windows 11 dual boot

### 5.2 Puesto avanzado (1 unidad)
- CPU: AMD Ryzen 9 7950X o Intel i9-14900K
- RAM: 64 GB DDR5
- GPU: NVIDIA RTX 4070 Ti SUPER (16 GB VRAM) o RTX 4080
- Almacenamiento: 2 TB NVMe SSD
- SO: Ubuntu 24.04 LTS (principal)

### 5.3 Servidor liviano opcional
- Mini PC con 64 GB RAM y 2 TB SSD para JupyterHub centralizado.

## 6. Infraestructura necesaria
- **UPS:** 6 kVA línea interactiva
- **Aire acondicionado:** Minisplit Inverter 24,000 BTU
- **Switch de red:** Gigabit 16 puertos (opcional 2.5G para puesto avanzado)
- **Cableado estructurado:** Cat6a a cada puesto
- **Eléctrica:** 2 circuitos dedicados de 20A con toma a tierra

## 7. Mobiliario
- 7 sillas ergonómicas
- 7 mesas (estándar y una más grande para puesto avanzado)
- Pantalla colaborativa 65" 4K
- Pizarra blanca o digital

## 8. Software (enfoque código abierto)
- SO: Ubuntu 24.04 LTS (gratuito)
- Visualización: Tableau Public, Power BI Desktop, Metabase, Apache Superset (gratuitos)
- IA/ML: Python, JupyterLab, TensorFlow, PyTorch, Scikit-learn (gratuitos)
- Colaboración: VS Code Live Share, JupyterHub (gratuito)
- Gestión de aula: Epoptes o Veyon (gratuitos)
- Bases de datos: PostgreSQL, SQLite, DuckDB (gratuitos)
- **Costo anual opcional:** $500 USD (licencia educativa para profesor)
